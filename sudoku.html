Sudoku

Aplicación web de Sudoku con generación automática de puzzles mediante backtracking, tres niveles de dificultad, temporizador con récord local, sistema de pistas y modo apunte que calcula automáticamente los candidatos de cada celda.

Ver en GitHub

Sobre el proyecto _

Sudoku es una aplicación web completa donde el servidor (Python + Flask) se encarga de toda la lógica del juego: genera puzzles únicos en cada partida, valida las respuestas del usuario y calcula qué números son posibles en cada celda vacía.

El frontend está construido en Vanilla JS sin ninguna librería externa, comunicándose con el servidor mediante fetch y JSON. Incluye un sistema de temas (modo oscuro + cinco paletas de color) que persiste entre sesiones usando localStorage.

Funcionalidades _

  • 🧩
    Generación automática de puzzles

    Cada partida genera un tablero único e irrepetible mediante el algoritmo de backtracking con orden aleatorio.

  • ⚡
    Tres niveles de dificultad

    Fácil, medio y difícil, controlando el número de celdas eliminadas del tablero completo.

  • ⏱️
    Temporizador y récord personal

    Cronómetro en tiempo real con registro del mejor tiempo por dificultad guardado en localStorage.

  • 💡
    Sistema de pistas

    Hasta 3 pistas por partida que revelan una celda incorrecta o vacía de forma aleatoria.

  • ✏️
    Modo apunte

    Muestra automáticamente los números candidatos en cada celda vacía y los actualiza al introducir un número definitivo.

  • 🎨
    Temas y paletas de color

    Modo oscuro y cinco paletas de color (azul, verde, púrpura, rosa, naranja) que se guardan entre sesiones.
